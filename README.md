A one-sentence pitch for make.fun's "A Day of One-Line Pitches" bounty: a single sentence, at most 240 characters, written to convince a friend who has never coded to let an AI agent build their first app idea on make.fun. The program writes the sentence to `/output/entry.txt` — no code, no explanation, just the pitch.

## Run it

```sh
node main.ts
```
